## 目标

在 website-winui3 首页 hero 下方添加一行大字提示："如果你害怕下载到病毒可以去微软应用商店下载"，仅在宽屏（≥900px）设备显示。

## 改动文件（3 个）

### 1. `website-winui3/src/site/pages/HomePage.vue`

**模板**：在 `</header>`（第 80 行）之后、`<!-- 特性总览 -->` 之前插入：

```html
<!-- 微软应用商店提示（仅宽屏显示） -->
<p class="site-store-tip">
  {{ t('home.hero.store-tip') }}
  <a href="https://apps.microsoft.com/detail/9P15095X7MGB" target="_blank" rel="noopener noreferrer">{{ t('home.hero.store-name') }}</a>
  {{ t('home.hero.store-tip-end') }}
</p>
```

- "微软应用商店"做成链接（复用下载页的商店 AppID `9P15095X7MGB`，用户点"微软应用商店"直达商店页面）；整句拆分写法遵循 hero 内 license 行的既有先例
- 链接仅在"微软应用商店"这几个字上，其余为纯文字

**样式**：在 hero 样式区（`.site-hero-license` 之后）新增：

```css
.site-store-tip {
  margin: 0;
  padding: 16px 24px;
  text-align: center;
  font-size: 22px;          /* 相对 14px 基础字号算"大字"，与 hero 标题 44px 呼应 */
  font-weight: 600;
  line-height: 30px;
  color: var(--text-primary);
  background: color-mix(in srgb, var(--accent-base) 8%, transparent);  /* 浅色强调条幅，明暗主题都适用 */
}
.site-store-tip a {
  color: var(--accent-base);
  text-decoration: none;
  font-weight: 600;
}
.site-store-tip a:hover { text-decoration: underline; }
```

**响应式**：在现有 `@media (max-width: 900px)` 块（第 662 行）内追加 `.site-store-tip { display: none; }` —— 遵循项目惯例（默认显示、窄屏隐藏），900px 与 hero 折叠断点一致。

### 2. `website-winui3/src/site/Strings/zh-CN/Resources.ts`

在 `home.hero.license-link`（第 30 行）后新增 3 个 key：

```ts
"home.hero.store-tip": "如果你害怕下载到病毒可以到",

"home.hero.store-tip-end": "下载",
```

### 3. `website-winui3/src/site/Strings/en-US/Resources.ts`

对应新增英文：

```ts
"home.hero.store-tip": "Worried about malware? Get it from the",
"home.hero.store-name": "Microsoft Store",
"home.hero.store-tip-end": " instead.",
```
