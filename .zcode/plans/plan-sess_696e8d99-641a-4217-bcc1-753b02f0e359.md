# 移植「流氓软件克星」(RogueCleaner v2.0.16) 为 TubaWinUi3 内置工具

把 https://github.com/aakk007/RogueCleaner 的全部功能移植为 TubaWinUi3 的一个内置工具（单工具 + 页面内部导航，忠实原版 5 分区形态），并用内置右键菜单管理替代现有的外部下载版 ContextMenuMgrTool。

## 已确认的现状（探索结论）

- RogueCleaner 是纯 C# WinForms（.NET Framework 4.x，零 NuGet），9 个源文件约 1.2 万行，**后端 ~90% 是纯 BCL 代码可直接复用**（注册表/WMI/COM/文件 IO）。MIT 协议，可自由移植。
- TubaWinUi3 主项目已引用 `System.Management`（WMI）、`System.Drawing.Common`（图标提取），`dynamic` COM 在 .NET 10 内置可用——**大概率无需新增任何 NuGet 包**。
- 内置工具架构：`IBuiltinTool` + `BuiltinToolRegistry.RegisterDefaults()` 一行注册；复杂工具用 `App.MainWindow.NavigateToToolPage(typeof(ToolContentPage), new ToolContentPageParam{...})` 承载页面（Pattern B）；扫描清理 UI 骨架参考 `JunkCleanerTool`（1182 行，含统计卡片、进度、取消）；主题用 `ThemeService.CurrentElementTheme` + `ThemeColors`；逻辑放静态 Service 类以便 xUnit 测试（`InternalsVisibleTo` 已配置）。

## 实施步骤

### 第 0 步：拉取源码（只读参考，不进仓库）
- `git clone --depth 1 https://github.com/aakk007/RogueCleaner` 到 `%TEMP%\RogueCleaner-src`，作为移植对照。

### 第 1 步：后端移植 → `TubaWinUi3.WinUI3/Services/RogueCleaner/`（命名空间 `TubaWinUi3.Services.RogueCleaner`）

按类拆分原版单文件 `RogueCleanerV2.cs`（7141 行）并逐行移植（只替换 BCL 差异，逻辑不变）：

1. `Models.cs` — `Finding`(INotifyPropertyChanged→直接属性)、`ActionTarget`、`Risk/ActionKind/Status` 枚举、扫描警告、清理进度模型
2. `RuleCatalog.cs` — 20 条厂商识别规则、多证据评分、`WinVerifyTrust`(Authenticode)/`MsiGetProductInfo` P/Invoke、身份缓存、自测
3. `RegistryHelper.cs` — 注册表 hive/view 封装
4. `WindowsTaskApi.cs` — 计划任务 `Schedule.Service` COM（dynamic）
5. `ScannerEngine.cs` — **11 路并行扫描**（右键菜单/此电脑入口/网盘只读诊断/开机启动 Run 键/启动文件夹/后台服务/浏览器插件 NativeMessagingHosts/文件关联/计划任务/隐藏卸载入口/运行中弹窗守护进程）+ `IShellLinkW` 快捷方式解析 + `LooksLikeAdOrGuard` 行为特征 + `ChineseDisplayText` 中文映射 + 权限异常降级为扫描警告
6. `CleanerEngine.cs` — 清理（备份→执行→验证）、8 种动作（删键/删值/屏蔽 ShellExt/隔离文件/sc.exe 禁用服务/COM 禁用任务/定向调用卸载器/仅报告）、`manifest.json` 批次清单、恢复中心 RestoreBatch/RestoreResult（保留原备份格式，兼容性一致）
7. `RogueCleanerDataStore.cs` — 数据目录改为 `ConfigManager.GetDataDir() + "RogueCleaner/"`（backups/reports/logs/quarantine/state/feedback），替代原版"exe 旁目录"
8. `UserWhitelistStore.cs` — 本地白名单 JSON
9. `ContextMenuInventoryService.cs` + `ContextMenuDiscoveryService.cs` + `ContextMenuMutationService.cs` — 右键菜单全场景枚举（20+ 根路径）、启停/编辑/添加/删除、树级备份与恢复
10. `ContextMenuSpecialModules.cs` — ShellNew/SendTo/OpenWith/GUID 屏蔽
11. `ContextMenuAdvancedModules.cs` — WinX 快捷菜单/Win11 UWP 现代菜单（解析 AppxManifest.xml）/IE 旧式菜单/安全增强菜单（复制完整路径等 3 个配方）
12. `ContextMenuTitleProbe.cs` — 动态菜单标题探测；**改为进程内后台线程 + 超时 + 字符串提取降级**（原版子进程隔离模式不适用于 WinUI，此为唯一行为差异并注释说明）
13. `SoftwarePresentationResolver.cs` — 软件图标/身份解析（ExtractIconEx）
14. `FeedbackFeature.cs` — 误报/漏报 4 类报告、脱敏（用户名/SID/URL/token）、本地保存、GitHub issue 链接

明确**跳过**（属应用级能力，TubaWinUi3 已有更好实现）：更新检查（应用自带 GitHubReleaseService 更新）、单实例互斥、CLI 冒烟模式（改为 xUnit 测试）、`--elevation-resume`（本应用启动即提权）。
API 替换：`JavaScriptSerializer`→`System.Text.Json`、`WebClient`→`HttpClient`、`Application.ExecutablePath`→`Environment.ProcessPath`、WinForms 依赖全部留在 UI 层不进 Service。

### 第 2 步：工具注册 + 页面 UI

1. `Services/BuiltinTools/RogueCleanerTool.cs` — Id `rogue-cleaner`、名称「流氓软件的克星」、分类「安全工具」、`Kind=ProgressTask`（盾牌 Glyph）；`ExecuteAsync` 导航到新页面；`OnClose` 里取消扫描 CTS
2. `BuiltinToolRegistry.RegisterDefaults()` 追加一行注册
3. `Pages/RogueCleanerPage.xaml` + `.xaml.cs`（Pattern A 专用页，跟随 `WindowsOptimizePage` 的页头规范）：
   - 内部 `NavigationView` 5 个分区（映射原版）：**总览**（操作栏：开始扫描/清理勾选/勾选可清理/只勾低风险/恢复中心/证据报告/反馈/关于 + 4 张统计卡片 + 风险分色结果列表（风险/项目/软件/位置/影响/处理）+ 详情面板 + 右键白名单/反馈）、**启动项管理**（结果过滤器预设）、**右键菜单管理**（全量管理：启用/禁用/编辑/添加/删除/刷新 + 专用模块 + 高级兼容 子页）、**弹窗/流氓诊断**（过滤器预设 + 只读诊断）、**恢复中心**（批次列表→批次条目→恢复/删除/清理旧记录，二次确认）
   - 扫描在 `Task.Run` 并行跑，进度经 `IProgress`/DispatcherQueue 回 UI，页面内 ProgressRing + 阶段状态文本；主题全部走 `{ThemeResource}`/`ThemeColors`；确认对话框用 `ContentDialog` + `RequestedTheme`
4. **改造 `ContextMenuMgrTool.cs`**：保留 Id/名称/位置，`ExecuteAsync` 改为跳转「流氓软件的克星」的右键菜单管理分区，删除 `FindInstalledExe` 下载逻辑；内置替代后原描述更新为内置管理

## 风险与对策

- `dynamic` COM（Schedule.Service/IShellLinkW）在 .NET 10 + WinUI 可用；若构建报错则在 csproj 补 `Microsoft.CSharp`（内置，不加包）
- 大量代码移植时若个别原版 P/Invoke 结构在 x64/ARM64 有对齐问题，以 `AllowUnsafeBlocks` 已开启可直接使用，逐项构建验证
- 恢复中心备份格式保持与原版完全一致（原版用户数据不迁移，仅保证本工具内自洽）
- 未打包（unpackaged）运行已自动提权，管理员操作无碍；MSIX 打包场景权限不足时按原版逻辑降级为扫描警告并提示
