## 回退到 WinUI 3 系统默认字体

用户选择"彻底回退系统默认"。目标：删除 MiSans 自定义字体系统，全部文字恢复 WinUI 3 默认字体（Segoe UI Variable，中文自动回退微软雅黑），同时根治两个 bug（全局不生效、全是粗体）。

### 问题根因（已调查确认）
1. **全是粗体**：捆绑字体只有 MiSans **Medium（380）** 一个字面，Normal/SemiBold/Bold 全部匹配同一字面 → 全粗且无层次。
2. **全局不生效**：`{StaticResource AppFontFamily}` 在 XAML 解析时一次性求值，`FontService.ApplySavedFonts()` 事后替换资源字典对已解析元素无效；且 MainWindow/HomePage 在它执行前就已解析。隐式样式仅覆盖 3 种控件，ContentDialog/Flyout/ToolTip 等走主题资源从未被覆盖。

### 改动清单

**1. `TubaWinUi3.WinUI3/App.xaml`** — 删除 `MiSansFont`、`AppFontFamily` 两个资源定义和第 16–29 行 3 个隐式样式（TextBlock/ContentControl/NavigationViewItem，只设 FontFamily + 无意义的 Opacity=1.0）。删除后全部控件回到 WinUI 原生默认（XamlControlsResources 主题资源，天然覆盖弹窗/菜单/提示等所有控件）。

**2. `TubaWinUi3.WinUI3/App.xaml.cs:151`** — 删除 `FontService.ApplySavedFonts();` 调用。

**3. `TubaWinUi3.WinUI3/Services/FontService.cs`** — 整个文件删除（无其他引用）。

**4. `TubaWinUi3.WinUI3/Pages/SettingsPage.xaml`** — 删除第 626–671 行"界面字体"卡片（`SettingsInterfaceFontCard`，含 FontComboBox + ResetFontButton）。**保留"水印字体"卡片不动**（独立功能，键为 ScreenshotWatermarkFont）。

**5. `TubaWinUi3.WinUI3/Pages/SettingsPage.xaml.cs`** — 删除：字段 `_fontInitializing`/`_fontChangePending`（36–37 行）、第 198 行 `InitInterfaceFontSettings()` 调用、`InitInterfaceFontSettings()`（997–1002）、`InitFontComboBox()`（1004–1028）、`FontComboBox_SelectionChanged`（1030–1039）、`ResetFontButton_Click`（1041–1050）、`ShowRestartHint`（1052–1067）。水印字体相关代码保留。

**6. 删除全部 `FontFamily="{StaticResource AppFontFamily}"` 属性（约 40 处）**：
- `MainWindow.xaml`（90、183、190、205）、`Styles/SettingsStyles.xaml`（14，SectionHeaderStyle 的 Setter）
- `Controls/UpdateBanner.xaml`（38、57、69）、`Controls/BrandBackgroundBanner.xaml`（37、48）
- `Pages/BuiltinToolsPage.xaml`（210）、`CommunityToolsPage.xaml`（242、249、258、267、282、288、303）、`DownloadQueueFlyout.xaml`（82、89、104、124）、`HardwareDetailPage.xaml`（21 及 39–183 共 17 处）、`HardwarePage.xaml`（409、422、445）、`FavoritesPage.xaml`（262、269、278、296、336）、`HomePage.xaml`（332、340、346、370、379、435、533）、`WindowsImagePage.xaml`（189）
- 删除后这些元素继承 WinUI 默认字体，字号/字重等其余属性保持不变（显式 SemiBold/Bold 在可变字体下会真实生效，层次恢复正常）

**7. 代码中的字体引用**：
- `Pages/BuiltinToolsPage.xaml.cs` — 删除第 17 行 `_appFont` 字段及第 137、151 行 `FontFamily = _appFont` 赋值（动态创建的 TextBlock 用默认字体）
- `Pages/FavoritesPage.xaml.cs:161` — 删除 `FontFamily = ...Resources["AppFontFamily"]` 赋值

**8. `TubaWinUi3.WinUI3/TubaWinUi3.csproj`** — 删除 `<Content Include="Fonts\*.ttf;Fonts\*.otf">` 块（33–36 行）和 `GenerateBundledFontSubset` target（约 135–144 行）。

**9. 删除字体文件与构建脚本**：`TubaWinUi3.WinUI3/Fonts/` 目录（MiSans-Medium.otf ~6.5MB + MiSans-Subset.otf，若被 git 跟踪则用 `git rm`）和根目录 `build-font-subset.ps1`（仅被 csproj target 引用）。

**10. 残留数据**：已保存的 `InterfaceFont` 设置键留在 settings.json 中，无代码读取即自然失效，不做迁移。
